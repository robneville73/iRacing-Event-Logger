This project's goal is to create a set of scripts that can connect to the iRacing SDK and stream information about a session and inspect that data in order to produce a useful log of "interesting events" that can be consumed by other downstream applications to facilitate automations of one sort or another. For example, we might want to log information about close battles on track to feed into another program that's controlling the camera angles in iRacing's replay so that the viewer is watching the most exciting things. For another example, we may want to feed information about significant events per car/driver (things like, a pass was made, they had a spin, they pitted, they got passed, they changed drivers [in endurance racing], they have a close battle happening, etc.) that might be used by another program that's trying to automatically edit video of a race with a focus on a particular driver so that it knows what to cut, what to keep and what to focus on. The point is, the use cases of downstream programs is incidental to what this one is supposed to do. The point of this one is to create a formatted log in JSON that can be easily consumed by other downstream programs.

This program should accept a command-line argument (or alternatively a configuration file) to specify the name of a driver/car to focus on to make sure that the log file doesn't get out of hand keeping track of many cars/drivers. That is to say, one underlying assumption here is that this logger assumes that downstream consumers are interested in a particular driver or car. The log should be organized by lap.

This program should automatically control iRacing as much as practical in order to gather this log.
